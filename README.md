# Exercícios de Java — Generation Brasil

Listas de exercícios de lógica de programação em Java resolvidas durante o bootcamp Generation Brasil, organizadas por assunto.

## Conteúdo

| Pasta (`src/`) | Assunto |
|---|---|
| `variaveisOperadores` | Variáveis, entrada de dados com `Scanner` e operadores |
| `Lacos Concidionais/If` | Estruturas condicionais `if` / `else` |
| `Lacos Concidionais/Switch` | `switch case` |
| `lacos de repetição/For`, `While`, `DoWhile` | Laços de repetição |
| `vetores` | Vetores e matrizes |
| `collection`, `collection2` | `ArrayList`, `Set`, filas e pilhas |

## Como executar

Importe a pasta no Eclipse ou IntelliJ como projeto Java (JDK 17+) e execute o exercício desejado.

## Tecnologias

- Java 17
